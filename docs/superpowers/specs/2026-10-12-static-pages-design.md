# Static marketing pages — design

Date: 2026-10-12  
Status: Approved for implementation  
Scope: `/about`, `/privacy`, `/vip`, `/articles`, `/faq`

## Approach

Shared static page shell + bilingual copy in a content module. Articles page combines 3 static editorial cards with newest published documents from the API.

## Pages

- **About** — mission, audience, what you can do, CTAs
- **Privacy** — policy sections for current membership product
- **VIP** — benefits, Member vs VIP, contact CTAs (no online payment)
- **Articles** — static editorials + latest documents
- **FAQ** — accordion Q&A + contact strip

Footer links: Latest articles → `/articles`, FAQ → `/faq`.
